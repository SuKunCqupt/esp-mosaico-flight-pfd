# app_game_runtime

Engine adapter: touch input (tap / long-press menu), menu actions, toasts,
calibration feedback, 1 Hz attitude log, and composing `pfd_view_t` from the
sensor (`app_sensors`) and phone-GPS (`app_link`) snapshots for `app_pfd`.
Started from the ESP-Mosaico blank game template (Apache-2.0 headers kept).
