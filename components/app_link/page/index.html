定位不工作？
  1. 要在户外或窗边，第一次定位可能要等 10–60 秒；速度和高度要等 GPS 真正锁定后才有。
  2. iPhone：设置 → 隐私与安全性 → 定位服务 → 打开；并把「Safari 浏览器网站」设为「使用 App 期间」。弹窗问「允许定位」时选允许，最好打开「精确位置」。
  3. 安卓：手机设置里打开「位置信息」；Chrome 弹窗问位置权限时选「允许」。如果选错了：点地址栏左边的图标 → 权限 → 位置 → 允许。
  4. 安卓连上飞行表热点后如果提示「此网络无法访问互联网」，请选「保持连接」；网页打不开时，临时关掉「移动数据」再刷新。
  5. iPhone 微信/QQ 里扫码打开的页面不能定位，请用 Safari 打开；安卓请用 Chrome。
iPhone 安装证书（只需一次，可选）

大多数 iPhone 在警告页点「显示详细信息 → 访问此网站」后就能定位。如果点了开始定位却没有弹出权限窗口，或者显示「不能使用定位」，就装一下这张只属于这块板子的证书：

  1. 点 下载证书，弹窗选「允许」。
  2. 打开 设置 → 通用 → VPN与设备管理（或顶部的「已下载描述文件」）→ FlightPFD Local CA → 安装。
  3. 设置 → 通用 → 关于本机 → 最下面「证书信任设置」→ 打开「FlightPFD Local CA」。
  4. 回到 Safari，打开 https://192.168.4.1，地址栏不再报警告。

这张证书只能用于 192.168.4.1 等板子自己的地址，签发它的私钥生成后已销毁。不用时可在「VPN与设备管理」里删除。

让飞行表连接手机热点 / 家里 Wi-Fi（可选）

默认用飞行表自己的热点就行。如果想让手机同时能上网，可以让飞行表连到你手机的个人热点或家里的 Wi-Fi，然后在飞行表屏幕「手机定位」页上看到新的网址。
